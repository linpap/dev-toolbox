# Dev Toolbox

A collection of 13 lightweight, privacy-friendly web tools built with pure HTML, CSS, and vanilla JavaScript. No accounts, no tracking, no frameworks.

## Tools

| Tool | Description | Repo |
|------|-------------|------|
| **Color Palette Generator** | Generate palettes with a color wheel, 18 harmony modes, and export to CSS/Tailwind/JSON/SVG | [color-palette](https://github.com/linpap/color-palette) |
| **Markdown to HTML** | Live preview with 3 themes, syntax highlighting, auto table of contents, drag & drop | [markdown-converter](https://github.com/linpap/markdown-converter) |
| **Pomodoro Timer** | Focus timer with SVG progress ring, audio alerts, configurable sessions, daily log | [pomodoro-timer](https://github.com/linpap/pomodoro-timer) |
| **JSON Formatter** | Format, minify, validate JSON with syntax highlighting, tree view, line numbers | [json-formatter](https://github.com/linpap/json-formatter) |
| **Password Generator** | Crypto-secure passwords, strength meter, batch mode, exclude ambiguous chars | [password-generator](https://github.com/linpap/password-generator) |
| **Unit Converter** | 50+ units across 8 categories with real-time conversion and formula display | [unit-converter](https://github.com/linpap/unit-converter) |
| **Regex Tester** | Live match highlighting, capture groups, replace mode, cheatsheet sidebar | [regex-tester](https://github.com/linpap/regex-tester) |
| **Lorem Ipsum Generator** | Placeholder text in 4 styles (Latin, Hipster, Tech, Pirate) with HTML output | [lorem-ipsum](https://github.com/linpap/lorem-ipsum) |
| **QR Code Generator** | Custom colors, 3 sizes, error correction levels, download as PNG or SVG | [qr-generator](https://github.com/linpap/qr-generator) |
| **CSS Gradient Generator** | Linear, radial, conic gradients with color stops, presets, and copy CSS | [gradient-generator](https://github.com/linpap/gradient-generator) |
| **Base64 Encoder/Decoder** | Real-time encode/decode, file drag & drop, URL-safe mode, Unicode support | [base64-tool](https://github.com/linpap/base64-tool) |
| **Word Counter** | 8 real-time stats, word frequency chart, keyword density, case transforms | [word-counter](https://github.com/linpap/word-counter) |
| **Stopwatch** | Precise timing with lap tracking, fastest/slowest highlights, CSV export | [stopwatch](https://github.com/linpap/stopwatch) |

## Philosophy

- **Zero dependencies** — no npm, no build steps, no frameworks
- **100% client-side** — nothing leaves your browser
- **Privacy first** — no analytics, no cookies, no tracking
- **Lightweight** — each tool is just 3 files (HTML + CSS + JS)
